# tutos.jessy-david.dev

Plateforme de tutoriels créer par Jessy DAVID.

## 🛠️ Stack technique

-   **Framework** : Next.js 16 (App Router)
-   **Langage** : TypeScript
-   **Styling** : Tailwind CSS
-   **Animations** : GSAP
-   **Base de données** : PostgreSQL + Prisma
-   **Authentification** : NextAuth v5 (Discord)

## 📝 Fonctionnalités

-   Affichage des tutoriels en markdown
-   Panel admin avec éditeur markdown
-   Gestion des catégories
-   Estimation du temps de lecture
-   Animations fluides
